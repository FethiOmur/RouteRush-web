# RouteRush website (routerushapp.com)

Static marketing site on GitHub Pages behind Cloudflare. `README.md` covers structure, the locale build and the `?nomap=1` test mode. Two things it doesn't say:

- Cloudflare caches `/assets/*` for 24 hours, 404 responses included. Don't request a new asset URL until the Pages build has finished (`gh run list --repo FethiOmur/RouteRush-web --limit 1` shows `completed success`). If a URL was cached as a 404, rename the file and update its references rather than purging; prefer a new filename over overwriting an asset. The cache rule lives in the Cloudflare dashboard, not in this repo.
- English at the root is the only hand-edited source. `tr/ it/ de/ es/ fr/` and `sitemap.xml` are generated by `python3 tools/build-locales.py`; change the English page and rebuild (`--check` fails if the committed output is stale).
