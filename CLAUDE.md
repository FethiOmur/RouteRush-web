# RouteRush website (routerushapp.com)

Static marketing site served by the `routerush-site` Cloudflare Worker (static assets, deployed by Workers Builds on every push to `main`; see "Hosting" in `README.md`, which also covers structure, the locale build and the `?nomap=1` test mode). Things it doesn't say:

- Don't request a new asset URL until the Worker deploy has finished (Cloudflare dashboard → Workers & Pages → routerush-site → Deployments, or the new file answers 200 on routerushapp.com). Before the 2026-11-09 move off GitHub Pages, a zone cache rule kept `/assets/*` 404s for 24 hours; if a URL ever gets stuck as a 404, rename the file and update its references rather than purging, and prefer a new filename over overwriting an asset.
- The default `npx wrangler deploy` deploys `wrangler.toml`, which is the separate `share-links` Worker, not the site. The site's config is `wrangler.site.jsonc`.
- English at the root is the only hand-edited source. `tr/ it/ de/ es/ fr/` and `sitemap.xml` are generated by `python3 tools/build-locales.py`; change the English page and rebuild (`--check` fails if the committed output is stale).
